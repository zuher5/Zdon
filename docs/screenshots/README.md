# Screenshots

Place app screenshots in this directory and reference them from the README.

Suggested set:

| File | Screen |
| --- | --- |
| `home.png` | Home screen with URL input |
| `analysis.png` | Format selection after analysis |
| `downloads.png` | Active download queue |
| `history.png` | Download history |
| `settings.png` | Settings |

Capture with:

```bash
adb exec-out screencap -p > docs/screenshots/home.png
```

Prefer a consistent device and theme across all shots.
