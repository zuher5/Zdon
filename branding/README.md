# Branding assets

Source assets that are not packaged into the APK.

| File | Purpose |
| --- | --- |
| `play_store_512.png` | 512×512 store / repository listing icon |
| `splash_icon_1152.png` | High-resolution splash source |

Launcher icons live in `app/src/main/res/mipmap-*/` and are the ones actually
compiled into the app. Keep the two in sync when the branding changes.
